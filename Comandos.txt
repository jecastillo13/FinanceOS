FINANCEOS - COMANDOS ÚTILES
===========================

Todos los comandos deben ejecutarse desde:
C:\Users\USUARIO\FinanceOS


1. EJECUTAR LA APLICACIÓN WEB
-----------------------------

streamlit run financeos.py

Abrir en el computador:
http://localhost:8501

Para permitir acceso desde otro dispositivo de la misma red:

streamlit run financeos.py --server.address 0.0.0.0 --server.port 8501

Consultar la IP privada del computador:

ipconfig

En el teléfono se abre:
http://IP-DEL-COMPUTADOR:8501


2. EJECUTAR LA API
------------------

uvicorn api.main:app --reload --port 8000

Documentación interactiva:
http://127.0.0.1:8000/docs

Para permitir conexión desde la aplicación móvil:

uvicorn api.main:app --reload --host 0.0.0.0 --port 8000

En el teléfono o aplicación móvil:
http://IP-DEL-COMPUTADOR:8000


3. DETENER STREAMLIT O LA API
-----------------------------

Presionar:
Ctrl + C


4. EJECUTAR PRUEBAS
-------------------

Validación rápida de lo preparado para commit:

powershell -ExecutionPolicy Bypass -File scripts/verificar_commit.ps1

Pruebas de backend, web y móvil antes de subir:

powershell -ExecutionPolicy Bypass -File scripts/verificar_push.ps1

Validación integral con auditoría de dependencias:

powershell -ExecutionPolicy Bypass -File scripts/verificar_completo.ps1

Solo pruebas Python:

python -m pytest -q

El resultado correcto termina con:
OK

Instalar los hooks automáticos una sola vez:

powershell -ExecutionPolicy Bypass -File scripts/install_hooks.ps1


5. REVISAR CAMBIOS DE GIT
-------------------------

git status

Ver las diferencias del código:

git diff


6. CREAR UN COMMIT
------------------

Agregar únicamente los archivos indicados para cada cambio:

git add ruta-del-archivo-1 ruta-del-archivo-2

Crear el commit:

git commit -m "feat: descripción del cambio en español"

Subirlo a la rama principal:

git push origin main

Confirmar el resultado:

git status


7. RETIRAR UN ARCHIVO DEL COMMIT SIN BORRARLO
---------------------------------------------

git restore --staged ruta-del-archivo


8. ARCHIVOS QUE NO DEBEN AGREGARSE
----------------------------------

No agregar manualmente:

database/finance.db
__pycache__/
*.pyc
uploads/
.venv/

Estos archivos contienen datos locales, archivos generados o dependencias.


9. INSTALAR DEPENDENCIAS
------------------------

python -m pip install -r requirements.txt


NOTA
----

Los avisos de Git sobre LF y CRLF son normales en Windows y no representan un error.
============================================================
NUEVO FRONTEND REACT
============================================================

1. Iniciar la API (primera terminal):
   uvicorn api.main:app --reload --port 8000

2. Iniciar React (segunda terminal):
   cd frontend
   npm install
   npm run dev

3. Abrir en el navegador:
   http://localhost:5173

4. Validar la versión de producción:
   npm run build

============================================================
USUARIOS Y PUBLICACION
============================================================

Modo privado/local (predeterminado):
   FINANCEOS_PUBLIC_SIGNUP=false

El primer registro crea el superadministrador y luego se cierra el registro.

Modo público (todos los registros son usuarios normales):
   FINANCEOS_PUBLIC_SIGNUP=true

Crear un superadministrador desde la terminal privada del servidor:
   python scripts/create_superadmin.py --nombre "Administrador" --correo "admin@dominio.com"

La contraseña se solicita de forma oculta y no queda guardada en el historial.
No ejecutes este comando desde una terminal pública ni permitas elegir el rol
desde el frontend.

============================================================
DESPLIEGUE SEGURO (SERVIDOR)
============================================================

1. Crear configuración privada:
   Copy-Item .env.production.example .env

2. Generar clave para cifrar MFA:
   python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

3. Completar .env con dominio, PostgreSQL, SMTP y clave MFA.

4. Validar sin iniciar:
   docker compose -f compose.production.yml config

5. Construir e iniciar:
   docker compose -f compose.production.yml up -d --build

6. Ver estado:
   docker compose -f compose.production.yml ps

7. Ver registros sin mostrar el archivo .env:
   docker compose -f compose.production.yml logs --tail 100 app proxy

No publiques el puerto 8000. Solo Caddy debe exponer 80/443.

============================================================
TARJETAS Y AVISOS BANCARIOS
============================================================

1. Abre el módulo Tarjetas y vincula cada tarjeta con su cuenta.
2. Pega el aviso bancario o revísalo desde la bandeja móvil.
3. Confirma categoría y medio de pago antes de guardarlo.
4. En crédito, FinanceOS crea la cuenta de deuda automáticamente.
5. Usa el botón Pagar para reducir la deuda sin duplicar el gasto.

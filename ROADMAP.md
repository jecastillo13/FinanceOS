# Roadmap de FinanceOS

## v0.6 — Base funcional

- [x] Cuentas y categorías.
- [x] Movimientos con actualización de saldo.
- [x] Catálogo de categorías agrupadas, editables y sin duplicados.
- [x] Transferencias internas entre cuentas.
- [x] Presupuestos mensuales por categoría.
- [x] Gastos recurrentes con pago desde una cuenta y registro automático en movimientos.
- [x] Dashboard de indicadores básicos.
- [x] Tasas de cambio y conversor.
- [x] Documentación inicial.

## v0.7 — Integridad financiera

- [ ] Reemplazar importes `Float` por valores decimales.
- [ ] Añadir transferencias entre cuentas.
- [ ] Mostrar claramente las cuentas excluidas por falta de tasa de cambio.
- [ ] Añadir validaciones y pruebas automatizadas de servicios.
- [ ] Unificar la capa de servicios heredada con `core/services/`.

## v0.8 — Dashboard Pro

- [ ] Distribución por cuenta y moneda.
- [ ] Gastos por categoría e ingresos mensuales.
- [ ] Flujo de caja y evolución patrimonial.
- [ ] Alertas de saldo y presupuesto.

## v0.9 — Metas e inversiones

- [ ] Metas de ahorro con fechas y progreso.
- [ ] Posiciones de acciones, ETF y cripto.
- [ ] Rentabilidad, dividendos y distribución de cartera.

## v1.0 — Reportes e inteligencia financiera

- [ ] Reportes en PDF y Excel.
- [ ] Comparativos por período.
- [ ] Resumen mensual y alertas inteligentes.
- [ ] Proyecciones y simulaciones de patrimonio.
